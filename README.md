## ส่วนที่ 1: Data Analytics Project (SMS Spam Detection)
การเปรียบเทียบประสิทธิภาพของโมเดล Machine Learning 3 วิธี ได้แก่ Multinomial Naive Bayes, Support Vector Machine (SVM) และ Deep Learning ในการจำแนกข้อความ SMS ว่าเป็นข้อความปกติ (Ham) หรือข้อความขยะ (Spam) 

### วิธีการรันโค้ด (How to run Part 1):
1. เข้าไปที่โฟลเดอร์ `data_analytics`
2. ติดตั้ง Library ที่จำเป็นโดยใช้คำสั่ง:
   ```bash
   pip install -r requirements.txt
   ```
3. เปิดและรันไฟล์ Jupyter Notebook `spam_classifier.ipynb`

## ส่วนที่ 2: Interactive Algorithm Visualizer Web Page (Gaussian Naive Bayes)
หน้าเว็บแอปพลิเคชันแบบหน้าเดียว (Single-Page Web App) สำหรับจำลองการทำงานของอัลกอริทึม Gaussian Naive Bayes ในรูปแบบ Interactive โดยรวบรวมทั้ง HTML, CSS และ JavaScript ไว้ในไฟล์เดียว การทำงานหลักแบ่งออกเป็น 3 ส่วน ดังนี้

*   **โครงสร้างและการแสดงผล (UI/UX):** ออกแบบด้วย HTML และ CSS ในสไตล์ Professional Dark Theme โดยใช้ Flexbox แบ่งหน้าจอเป็น 2 คอลัมน์ (ซ้าย-ขวา) ที่มี Scrollbar อิสระแยกจากกัน ฝั่งซ้ายประกอบด้วยพื้นที่รับข้อมูล (Data Canvas) และแผงควบคุม ส่วนฝั่งขวาใช้แสดงสถานะภายในของโมเดลและพื้นที่กราฟ 
*   **ระบบโต้ตอบข้อมูลบนกระดาน (Data Canvas & Controls):** ใช้ JavaScript ควบคุม HTML5 `<canvas>` เพื่อให้ผู้ใช้สามารถนำเมาส์ไปคลิกเพิ่มจุดข้อมูล 2 มิติ (พิกัด X, Y) โดยแบ่งเป็น 2 คลาส ได้แก่ Class 0 (สีฟ้า) และ Class 1 (สีแดง) นอกจากนี้ยังมีปุ่มสำหรับเคลียร์หน้าจอและปุ่มสุ่มข้อมูล (Random Data) ที่จะสร้างจุดข้อมูลจำลองแบบเกาะกลุ่มกัน (Cluster) ขึ้นมา 20 จุดโดยอัตโนมัติ
*   **ระบบคำนวณคณิตศาสตร์เบื้องหลัง (Model State):** เมื่อผู้ใช้กดปุ่ม "Step-by-step" ระบบจะดึงพิกัดของจุดทั้งหมดบนกระดานมาแยกตามคลาสและคำนวณค่าสถิติพื้นฐานของ Gaussian Naive Bayes ได้แก่
    *   **Prior P(C):** สัดส่วนความน่าจะเป็นของแต่ละคลาสเทียบกับจุดทั้งหมด
    *   **Mean (μ):** ค่าเฉลี่ยของพิกัดแนวแกน X และ Y เพื่อหาจุดศูนย์กลางของกลุ่มข้อมูล
    *   **Variance (σ²):** ความแปรปรวนของการกระจายตัวของข้อมูล (มีการบวกค่าตัวเลขเล็กน้อยเพื่อป้องกัน error กรณีความแปรปรวนเป็น 0)
    *   จากนั้นโค้ดจะนำค่าสถิติที่คำนวณได้ทั้งหมดไปแสดงผลแบบ Real-time ลงในตารางฝั่งขวาของหน้าเว็บ เพื่ออธิบายสถานะภายในของโมเดลให้เห็นภาพอย่างเป็นรูปธรรม
